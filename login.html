訂票監控

第一次使用：怎麼建立 Token？
  1. 打開 GitHub → Fine-grained token
  2. Token name 隨意（例如「訂票監控」），Expiration 選 1 年或自訂
  3. Repository access 選 Only select repositories → 只勾你的私人 repo
  4. Permissions → Repository permissions 設為 Read and write：
    Contents、Actions、Secrets、Variables
  5. 按 Generate token，複製貼到上面

Token 只存在這台裝置的瀏覽器，不會上傳到任何地方（只用來呼叫 GitHub API）。手機和電腦各登入一次即可；不用了可以到同一頁刪除 token。
